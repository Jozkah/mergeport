# Design source ledger

Kravio is the visual authority. It was inspected live in this build session (computed styles at 1024 px, screenshot at 390 px). The secondary sources below were inspected in the earlier research pass recorded in `reference-research.md` (28 Oct 2026); **they were not re-opened in this build session**, so entries for them repeat that note's findings and decisions rather than new observation.

| Source | Evidence | Observed pattern | Adopted / rejected | Access limits |
| --- | --- | --- | --- | --- |
| https://kravio-dashboard.vercel.app/ | Live: computed styles, screenshots at 1024 and 390 px | Canvas `#f8f8f8`, white surfaces, border `#e5e7eb`, ink `#1f2937`; Inter Variable; 250 px sidebar with search, grouped nav, white bordered active item with `0 4px 7px` shadow; panel shells with striped header and inset white surface; bars with `8 8 4 4` radius, ghost gradient, dark selected bar; dark segmented selection | **Adopted** wholesale: tokens, panel motif, sidebar, bar chart shape, segmented control. **Replaced**: support metrics/labels with repository workflows; no sparklines or trend percentages without history | Only the Overview was inspected; other routes of the reference were not |
| https://www.getlayers.ai/ (Vesper, Clarix) | Earlier research note | Atmospheric dark and textured presentation | **Rejected** for working surfaces (cinematic hero effects). Idea kept: restrained material depth only in panel headers | Premium assets gated |
| https://curated.design/ (Planes, ToDowl) | Earlier research note | Consistent component library; connected task/board/calendar views | **Adopted**: board, list and roadmap share one persisted data set and card vocabulary. **Rejected**: marketing hero composition | None noted |
| https://60fps.design/ (Things 3, GitHub badges) | Earlier research note | Contextual task-creation feedback | **Adopted**: inline confirmation text on saved actions. **Rejected**: decorative badge/logo animation | Pro catalog not accessed; continuous playback not verified |
| https://refero.design/ (public style pages only) | Earlier research note | Restrained neutrals, sparse accents (product-site analyses, not authenticated app flows) | Supports Kravio direction; nothing copied | Dashboard catalog returned placeholders; no connector/skill installed |
| https://reactbits.dev/ (Animated List, Warm Tooltip, Glide Select) | Earlier research note | Clear selection state, tooltip continuity | **Adopted**: clear selected/active state in segmented controls. **Rejected**: list entrance animation on updates (working lists stay still on polling); no dependency added | None noted |
| https://auragradients.vercel.app/ (Silver Mist, Arctic Frost) | Earlier research note | Faint cool gradients | **Not used** yet: tables, boards and reading surfaces stay flat. Reserved for onboarding/empty accents only | None noted |
| https://lucide.dev/icons/ | Earlier note plus this session: every icon import checked against the installed `lucide-react` exports | One outline icon family | **Adopted**: single family; stroke 1.5 beside regular text; names verified programmatically (`src/components/ui/icons.ts`) | None |
| https://www.webild.io/ | Earlier research note | Template material/composition | **Rejected** for operational screens | Full catalog needs login; gated templates not inspected |

Skills used for this build: Impeccable 4.7.0 (Operate mode; `init`, `new-work` for a pinned world, craft floor, mechanical detector), make-interfaces-feel-better (full review mode), transitions-dev / transitions-polish (token scale for dialog, drawer, tabs, toast), and the GSAP skills (gsap-react, gsap-core, gsap-plugins) for the board's layout animation, which uses `useGSAP` with a scoped ref and an interruptible `fromTo` on an inner wrapper so dnd-kit keeps ownership of drag transforms. Impeccable 4.8.0 exists upstream; the installed 4.7.0 was used and not updated.
